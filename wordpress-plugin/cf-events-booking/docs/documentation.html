Manuel du praticien & guide technique

Tout le site tient dans une seule extension

Réservations en deux clics, rendez-vous individuels, acompte en ligne, suivi après séance et newsletter maison — réunis dans un plugin sur mesure, sans dépendance payante, pensé pour soins.ewendaviau.com.

Version 1.9.0 Réservations Post-Séance Newsletter SumUp Google Agenda

01Vue d'ensemble

Ce plugin remplace à lui seul plusieurs extensions habituellement séparées (The Events Calendar, un plugin de réservation, un outil d'emailing). Il est organisé en un cœur « réservations » et deux modules autonomes qui s'activent avec lui.

Cœur — Réservations

Événements de groupe, rendez-vous individuels hebdomadaires, liste d'attente, emails, statistiques, synchronisation Google Agenda.

Module — Post-Séance

Séquence automatique de 4 emails après une séance individuelle. Le 4ᵉ (invitation) reste une validation manuelle, jamais un envoi automatique.

Module — Newsletter

Système d'emailing maison complet : abonnés, campagnes, envoi par lots, statistiques, A/B testing, automatisations — sans MailPoet.

◆

Les trois parties partagent le même code et la même base de données. Activer le plugin installe et met à jour automatiquement les tables et les tâches planifiées des deux modules.

02Installation & mise à jour

Deux méthodes, au choix.

Par l'interface WordPress (recommandé)

  1. Extensions → Ajouter → Téléverser une extension.
  2. Choisir le fichier cf-events-booking.zip, puis Installer.
  3. Pour une mise à jour, WordPress propose « Remplacer l'extension actuelle » : les données (réservations, abonnés, réglages) sont conservées.
  4. Activer l'extension.

Par FTP

Déposer le dossier cf-events-booking/ dans wp-content/plugins/, puis activer depuis l'écran Extensions.

✓

Migrations automatiques. Après une mise à jour par simple écrasement des fichiers, les nouvelles colonnes et tâches planifiées se créent d'elles-mêmes au premier chargement de l'administration — aucune réactivation nécessaire.

03Événements & ateliers

Les événements de groupe (soirées constellation, ateliers) se créent depuis le menu Événements. Chaque événement gère ses places, son prix, son lieu, sa liste d'attente et la date limite d'inscription.

Afficher les événements sur une page

// Liste des prochains événements
[cf_events]

// Limiter le nombre affiché
[cf_events nombre="6"]

// Filtrer par catégorie
[cf_events categorie="constellation"]

// Vue calendrier mensuel
[cf_events vue="calendrier"]   ou   [cf_calendrier]

La réservation se fait dans une fenêtre modale, sans quitter la page. Le visiteur reçoit un email de confirmation avec un fichier .ics pour son agenda ; une notification part vers l'administratrice.

04Rendez-vous individuels

Les séances individuelles fonctionnent par types de rendez-vous (menu Types RDV) : chaque type définit une durée, un prix, un lieu, et des créneaux hebdomadaires récurrents via le Planning.

// Widget de prise de rendez-vous pour un type donné
[cf_rdv type="constellation-individuelle"]

// Réservations de la personne connectée
[cf_mes_reservations]
◆

Le type accepte le slug (nom d'URL) ou l'identifiant numérique du type de rendez-vous. Le slug est visible dans la liste des types de RDV.

05Acompte en ligne (SumUp)

Pour sécuriser les créneaux et limiter les annulations, un acompte peut être demandé à la réservation. Réglages → onglet 💳 Paiement.

  1. Cocher Demander un acompte à la réservation.
  2. Coller le Personal Access Token SumUp (SumUp → Intégrations → Clés API) et l'email du compte SumUp.
  3. Fixer le montant de l'acompte (ex. 30 €), déduit du total en séance.
  4. Cocher les types de RDV concernés par l'acompte.

Après une réservation confirmée d'un type coché, la page de succès affiche un bouton de paiement et redirige vers SumUp au bout de 5 secondes ; le lien figure aussi dans l'email de confirmation.

!

La redirection n'est autorisée que vers pay.sumup.com. Tant qu'aucun token n'est renseigné, aucun paiement n'est demandé et le formulaire reste inchangé.

06Synchronisation Google Agenda

Réglages → onglet 📅 Google Agenda connecte un ou plusieurs agendas Google. Les créneaux déjà occupés y sont automatiquement retirés des disponibilités, et chaque nouvelle réservation crée un événement dans l'agenda.

✓

Événements « toute la journée » pris en compte. Un bloc de type journée entière (posé souvent depuis le mobile) rend indisponibles tous les créneaux du jour, même quand Google le marque « Disponible ».

07Emails automatiques

Réglages → onglet 📧 Emails centralise les messages transactionnels liés aux réservations.

08Module — Suivi post-séance

Après une constellation individuelle, une séquence de quatre emails accompagne la personne. Menu Post-Séance.

ÉtapeDélaiRôleEnvoi
Email 1 — Le soinJ+1Prendre soin de soi après la séanceAutomatique
Email 2 — Les nouvellesJ+7Prise de contact + article + WhatsAppAutomatique
Email 3 — Le témoignageJ+14Demande d'un retourAutomatique
Email 4 — L'invitationJ+28Proposition « Pleine Vie »Validation GO / NO-GO
!

Le 4ᵉ email ne part jamais tout seul. À J+28, une notification arrive à l'administratrice avec un brouillon et deux boutons. Chaque lien ouvre une page de confirmation (un simple clic d'un logiciel anti-spam ne peut pas déclencher l'envoi).

La détection se fait chaque jour à 8 h : les séances de la veille (statut confirmé ou présent) entrent dans la séquence. Un lien de désinscription figure sur chaque email client. Les thèmes d'article se règlent par ligne dans Post-Séance → Séquences, les URL des articles piliers dans les Paramètres.

09Module — Newsletter

Un système d'emailing maison, gratuit, sans MailPoet. Menu Newsletter, réparti en quatre écrans : Campagnes, Abonnés, Automatisations, Réglages.

Abonnés & inscription

Formulaire d'inscription à poser sur n'importe quelle page :

[cf_newsletter]

Double opt-in (confirmation par email), choix du rythme Quinzaine ou Mensuel, désinscription et page de gestion en un clic. Import / export CSV depuis l'écran Abonnés. La case à cocher du formulaire de réservation alimente directement cette liste.

Campagnes

Rédaction en brouillon (objet + corps, variables {{prenom}} {{nom}} {{email}}), puis choix de la cible et du segment. Rien ne part sans un clic explicite sur Lancer l'envoi — ou une programmation à une date choisie.

✓

Compatible copier-coller MailPoet. Un HTML copié depuis MailPoet (aperçu navigateur → code source) peut être collé tel quel dans le corps : le contenu utile est extrait, les variables MailPoet converties, son pied de désinscription retiré, et les mises en page en tableaux préservées à l'envoi.

  • Cible — Quinzaine + Mensuel (édition du 1ᵉʳ), Quinzaine seule (édition du 15), ou Mensuel seul.
  • Segment — tous, engagés (actifs sur 90 jours) ou inactifs (réengagement).
  • Email de test — s'envoyer le rendu réel avant de lancer.
  • Renvoi aux non-ouvreurs — relancer en un clic ceux qui n'ont pas ouvert.

A/B testing d'objet

Deux objets sont testés sur un échantillon (30 % par défaut, réparti moitié/moitié). Après 4 heures, l'objet le plus ouvert est envoyé automatiquement au reste des abonnés.

Automatisations

Email de bienvenue

Envoyé dès qu'un abonné confirme son inscription.

Notification d'article

À chaque nouvel article de blog publié, une newsletter est générée (brouillon à valider, ou envoi direct).

Modèles annuels (12 newsletters prêtes)

L'écran Newsletter → Modèles annuels contient les 12 éditions mensuelles déjà rédigées (une par mois, avec objet, corps et lien vers l'article pilier). Pour chaque édition, trois actions :

  • Créer le brouillon MailPoet — insère directement un brouillon dans MailPoet et ouvre son éditeur (visible si MailPoet est installé).
  • Créer dans le module intégré — crée une campagne dans le module Newsletter maison.
  • Copier le contenu — copie le HTML dans le presse-papier, à coller n'importe où.
◆

MailPoet n'offre pas d'API officielle de création de newsletter ; le brouillon est écrit dans sa table interne au format bloc « Texte ». Si une version de MailPoet refuse ce format, l'action le signale — utilisez alors « Copier le contenu ».

Envoi & délivrabilité

L'envoi se fait par lots toutes les 5 minutes avec un plafond quotidien, via une tâche planifiée. Les ouvertures (pixel) et les clics (redirection) sont suivis ; les liens vers le site sont balisés en UTM pour Google Analytics.

◆

SMTP intégré. Réglages → renseigner un compte email OVH (ssl0.ovh.net) : tous les emails du site partent alors par ce serveur authentifié, sans plugin tiers. Un envoi de masse fiable exige toujours un SMTP authentifié — ici, c'est votre propre boîte mail.

13Dépannage

Les emails arrivent en spam ou ne partent pas

Configurer le SMTP intégré (Newsletter → Réglages) avec un compte email OVH. C'est la cause la plus fréquente : l'envoi PHP brut depuis un hébergement mutualisé est peu fiable.

Un affichage semble figé après une mise à jour

Vider le cache du navigateur et celui de WP-Optimize. Le numéro de version force normalement le rechargement des fichiers CSS/JS.

Les créneaux ne tiennent pas compte de Google Agenda

Vérifier la connexion dans Réglages → Google Agenda et que l'agenda concerné est bien coché. Le cache des disponibilités est de 5 minutes.

Une newsletter reste bloquée en « envoi en cours »

Vérifier que cfnl_send_cron s'exécute (trafic du site ou cron serveur) et que le plafond quotidien n'est pas atteint.
